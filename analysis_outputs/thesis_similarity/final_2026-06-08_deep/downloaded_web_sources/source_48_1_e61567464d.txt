 Anchor point: Personal data disclaimer

 Personal data disclaimer

 By requesting an API key, you agree to the following terms:

 Email verification is used to ensure that API keys are secure and can only be overwritten by the owner of the email address. All email addresses are hashed before being stored in our database.

 The email domain name (e.g. gmail.com, ember-energy.org) will be used internally to help measure the impact of our data, but no processing will occur on any personal data.

 No data will be shared with partner organisations or any third parties.

 You can request to be deleted from our database at any time by contacting  [email protected] , but doing so will revoke access for your API key.
